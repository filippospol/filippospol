Analytics projects in R: collecting and cleaning basketball data, building metrics, and shipping them as interactive Shiny apps. The repositories here hold the scrapers, pipelines and app code behind the work on the [projects page](https://filippospol.github.io/bball-projects/).

#### What's here

- Scraper functions for Basketball Reference and PBP Stats, covering the NBA, WNBA, EuroLeague and the main domestic leagues.
- Lineup and on/off analysis, plus era-adjusted and playoff-scoring metrics.
- R Shiny apps for exploring the results, with scheduled data refreshes behind them.
- More work to be done.

#### Selected repositories

- **[bball-projects](https://github.com/filippospol/bball-projects)** ~ the R toolkit: Basketball Reference and PBP Stats scrapers, lineup analysis, and the data behind several of the apps.
- **[bball-stats](https://github.com/filippospol/bball-stats)** ~ NBA, WNBA and European-league box scores in one app, with a set of props tools.
- **[nba-watch-tracker](https://github.com/filippospol/nba-watch-tracker)** ~ a spoiler-free tracker for watched games, with a per-game hype score.
- **[FPM](https://github.com/filippospol/FPM)** ~ Fair Plus Minus, a RAPM-based EuroLeague player-impact metric with leaderboards back to 2007-08.

Adjusted Era Stats and Modern Playoff Scoring Runs don't have standalone repositories; their code and data sit inside `bball-projects`.
